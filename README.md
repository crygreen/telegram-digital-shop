# Telegram Digital Shop Bot

Асинхронный Telegram-бот для автоматизации продаж цифровых товаров. 
Проект написан на Python с использованием библиотеки `aiogram 3.x` и базы данных `SQLite`.

## 🚀 Основные возможности

* **Каталог товаров:** Вывод товаров с фото-превью и ценой.
* **Оплата в Telegram Stars (XTR):** Встроенная система платежей в один клик (без сторонних шлюзов).
* **Ручная оплата картой:** Отправка реквизитов, уведомление администратора о переводе и подтверждение оплаты в один клик.
* **Защита контента:** Отправка эксклюзивных файлов (после оплаты) с флагом `protect_content=True` (запрет на пересылку).
* **Анонимный чат (VIP):** Клиент может связаться с автором. Админ получает уведомление и может ответить клиенту прямо через бота (используется `ForceReply` для связи сообщений).
* **Статусы:** Админ может переключать статус онлайн/оффлайн (`/online` и `/offline`), клиентам будет уходить автоответ, если админ недоступен.
* **Панель администратора:** Добавление новых товаров через FSM (загрузка названия, цены, превью и скрытого фото).

## 🛠 Стек технологий

* Python 3.10+
* aiogram 3.15 (асинхронный фреймворк для Telegram Bot API)
* SQLite3 (встроенная база данных)
* python-dotenv (безопасное хранение токенов)

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/telegram-digital-shop.git
   cd telegram-digital-shop
Создайте и активируйте виртуальное окружение:

   python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

Установите зависимости:
pip install -r requirements.txt

Создайте файл .env в корне проекта и добавьте свои данные (по примеру .env.example):
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id

Запустите бота:
python main.py

Структура проекта
main.py — основной файл с хендлерами (команды, оплата, чат, FSM админки).

database.py — модуль для работы с SQLite (создание таблиц, добавление товаров, сохранение связей для чата).

requirements.txt — список зависимостей.

.env.example — шаблон для переменных окружения (токен, ID админа).
